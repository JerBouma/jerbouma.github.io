A run can be kept, shared and read back without calibrating or simulating again: `write_run` and `read_run` store a run with its settings and calibration, `publish_calibration` and `load_release` save a calibration under a version tag with its validation report, `Snapshot` keeps a factor set calibrated as of one month so later runs replay it in seconds, and `Reporting` shows simulated prices in one reporting currency, each scenario converted at its own simulated exchange rate.
