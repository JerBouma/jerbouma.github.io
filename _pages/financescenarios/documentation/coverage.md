The single, up-to-date reference for **what this project can and can't do, and why**: every factor, every calibration method, every measure (real-world vs risk-neutral), and every known gap, in one place. Synthesized from this project's internal research/design history, the infrastructure pages in the [documentation](/projects/financescenarios/docs) and each factor's own class docstring (`help(...)`), where a factor's Scope notes now live. There is no second copy to keep in sync.

`financescenarios.coverage` also surfaces the config-triggerable subset of this at run time: `Scenarios.calibrate(config)` logs a notice (at INFO, once per session, so `set_log_level("INFO")` prints it) for any configured factor/method that has a known, more capable alternative documented below but not yet available.

Every row below names both a **Location** (the config field, module, or doc page where that status lives) and a brief **Explanation** (what it does, or precisely why it's unavailable).

**Legend:** <span class="cov cov--yes">Available</span> <span class="cov cov--part">Partial</span> (simplified) <span class="cov cov--no">Not available</span>

| Interest rates | Stochastic deflator (Cheng & Planchet 2018) | <span class="cov cov--part">Partial</span> | `KnwSvQ.deflator()`, `KnwSvQ` | Real Radon-Nikodym-derivative-based pricing kernel built from an already P-measure-simulated `knw_sv` run's own paths.
