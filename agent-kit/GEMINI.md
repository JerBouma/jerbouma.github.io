# Gemini CLI

All project instructions live in `AGENTS.md`, so every agent follows the same rules. Read
`AGENTS.md` at the start of every session and follow it. Step-by-step instructions for recurring
tasks are in `.claude/skills/<name>/SKILL.md`; read the matching one before starting such a task.

(Alternatively, configure Gemini CLI to read `AGENTS.md` directly through the context file name
setting in `.gemini/settings.json`, and delete this file.)
